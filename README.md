# Sineklik Avusturya

Avusturya'ya hızlı teslimatlı sineklik, plise perde, jaluzi ve zip perde sistemleri.

Kaliteli perde çözümleri için [Fenetre Systems](https://www.fenetresystems.com) tarafından üretilmektedir.

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Özellikler

- Plise sineklik sistemleri
- Plise perde ve jaluzi
- Zip perde ve honeycomb
- Düet perde çözümleri
- 4-10 günde Avusturya teslimatı
